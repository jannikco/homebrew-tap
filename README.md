# jannikco/homebrew-tap

Homebrew casks for [HeyBotOS](https://github.com/jannikco/heybotos).

```sh
brew install --cask jannikco/tap/heybotos
```

Then open HeyBotOS. It needs at least one of the coding CLIs `claude`, `codex` or `grok`, installed and
signed in with your own subscription.

To remove it: `brew uninstall --cask heybotos` (add `--zap` to delete your data in `~/heybotos` too).
